# What's changed

* Sound follows the headset: when the HyperX headset turns on, it becomes the default output; when it turns off, sound returns to the speaker you were using (or the first ordinary output). Toggle with **Switch sound to headset** in the tray menu; on by default. Nothing to set up.
* Headset on/off is detected instantly from reports the dongle pushes on its own, instead of polling.
* `BatteryDiagnostics.exe` lists sound outputs and has `--listen [seconds]` to print the headset dongle's own reports.
* Removed leftover upstream code: the HeadsetControl C++ library and submodule, unused language, update-check and resource-icon code, and unused dependencies. Builds are faster.
