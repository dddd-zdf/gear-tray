# What's changed

* Renamed from Battery Status to **Gear Tray**. The exe is now `GearTray.exe` (diagnostics: `GearDiagnostics.exe`) and the log `gear-tray.log`. Settings, the Start with Windows entry and the Start menu shortcut move over automatically on first run. Nothing to do.
* Sound follows the headset: when the HyperX headset turns on, it becomes the default output; when it turns off, sound returns to the speaker you were using (or the first ordinary output). Toggle with **Switch sound to headset** in the tray menu; on by default.
* No more polling. On/off and battery changes for both the headset and the mouse come from reports the devices push on their own, so the tray updates instantly. Devices are read in full only at startup, on Refresh, and after the dongle or receiver is replugged.
* `GearDiagnostics.exe` lists sound outputs and has `--listen [seconds]` to print the devices' own reports.
* Removed leftover upstream code: the HeadsetControl C++ library and submodule, unused language, update-check and resource-icon code, and unused dependencies. Builds are faster.
